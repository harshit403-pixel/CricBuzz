# CricBuzz

## Project Description

CricBuzz is a cricket management and live scoring platform. The project is planned as a student team application that can help users follow matches, view scores, explore teams and players, and manage match-related updates from an admin or scorer side.

## Purpose of the Project

The purpose of this project is to build a platform that combines cricket information, live match tracking, and team-side management in one place. It can also help the team practice full-stack development, collaboration, and structured project planning.

## Possible User Types

- Public users who want to view matches, teams, players, and live score updates
- Team members or admins who manage content and platform data
- Scorers or admins who update live match information and score-related details

## Main Modules

- Matches
- Live score
- Teams
- Players
- Scorecard
- Points table
- News and updates
- Admin or scorer panel

## Initial Development Approach

- Start with a clean project structure and simple planning
- Build reusable modules and common UI or logic where possible
- Use static data or mock flows in the beginning if needed
- Connect backend and API integration step by step later
- Keep the plan flexible so the team can adjust after discussion

## Draft Direction

This overview is meant to guide the early stage of the project, not lock the team into a final structure. The project direction can be updated after mentor instructions, team discussion, and official task assignments.
